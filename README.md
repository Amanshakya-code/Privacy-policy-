# Amihub Privacy Policy

Last updated 24 November 2026

Aman Kumar (AmanShakya on Google Play) develops Amihub - Amity Amizone App, an unofficial app for Amity University students. This policy explains how Amihub handles information when you use the app.

## Information Amihub uses

- **Amizone sign-in and academic information.** The app opens Amizone for sign-in. Your password goes to Amizone through its sign-in page. Amihub stores session cookies in encrypted storage on your device and uses them to request your profile, attendance, courses, timetable, faculty information, exam schedule and results. Some academic information is cached on your device.

- **Student records.** When a student profile is available, Amihub can save one record per student per day to Cloud Firestore. It can include your name, admission or enrollment number, programme, semester, passing year, Firebase user ID and timestamps. Authorized administrators use these records for daily student counts. They can also manage a separate student directory that can include contact details and access status. Directory changes record the action, time and administrator ID.

- **Campus Live.** If you join chat, Amihub uses a Firebase user ID, session information, display alias and activity timestamps to run chat, show presence and enforce moderation. It stores your messages, reactions and reports when you submit them. Other chat participants can see the alias, status, messages and reactions you share in the room. Moderators can review reports, which can include message excerpts, participant identifiers and the reason for the report.

- **Usage and diagnostics.** Google Firebase Analytics, Crashlytics and related Google services can process app interactions, device and app information, installation identifiers, crash reports and diagnostics to measure use, troubleshoot crashes and operate the app. Firebase Cloud Messaging can use installation identifiers and messaging tokens to deliver notifications.

## Service providers and external sites

Amihub sends academic requests to Amizone. Older versions can route academic requests through Amihub’s academic service, which uses Amizone session information to fetch the requested data. Amihub uses Google Firebase to provide cloud storage, authentication, chat, messaging, analytics and crash reporting. Firebase uses an anonymous sign-in for features that need a user ID. This ID can still link activity across app features.

Amihub also loads public notes and opportunities from external sources such as Blogger, Unstop and Amity’s public placement notices. When you visit an external resource, that provider handles your request under its own privacy practices. Google’s privacy information is available in the [Google Privacy Policy](https://policies.google.com/privacy).

## Security, retention and deletion

Amihub uses encrypted connections for Amizone and Firebase requests, encrypts Amizone session cookies on the device and uses Firebase access rules for stored records. Student records are available to authorized administrators.

Campus Live messages are designed to expire from the room after 15 minutes. Moderation reports and restrictions can be retained to handle abuse. Amihub keeps student records, directory logs and diagnostics for service operation, administration and troubleshooting. Firebase service settings also govern retention of analytics and diagnostics.

You can clear local app data in Android settings. To request access, correction or deletion of information Amihub stores, contact the developer with enough information to identify the record. The developer may need to verify your identity. For changes to university records, contact Amity through Amizone.
